# RPT — Remote Proxy Tunnel

Удалённый доступ к роботам по **SSH** и **SFTP** через центральный сервер с
веб-панелью в стиле **Termius**. Роботы сами поднимают обратный SSH-туннель до
сервера (работают из-за NAT), администратор из браузера подключается к любому
роботу и принимает/отклоняет новые подключения «по кнопке».

Полное описание — в [`DOCUMENTATION.md`](DOCUMENTATION.md).

## Быстрый старт

### 1. Сервер (один раз)
```bash
sudo bash server-install.sh
```
Спросит порт веб-панели (не 80/443), порт хаба, внешний адрес и пароль админа,
поднимет всё в Docker и покажет адрес панели.

### 2. Робот (на каждом роботе)
```bash
sudo bash robot-install.sh
```
Спросит серийник, имя, адрес сервера. Создаст пользователя `RM` (пароль
`536yfj67`) с правами sudo, поднимет туннель в Docker.

### 3. Сопряжение «по кнопке»
1. В веб-панели → **«🔑 Синхронизация ключей»** → появится код.
2. На роботе установщик сам запросит код (или позже: `sudo rptctl sync`).
3. В панели → **«Ожидают подтверждения»** → **✓ Принять**.

Робот загорится зелёным — жмите **SSH** или **SFTP**.

## Управление
- Сервер: `rptctl` (`status | logs | restart | set-port | set-password`)
- Робот:  `rptctl` (`sync | status | logs | restart | stop | start`)

> ⚠️ Значения по умолчанию (`RM` / `536yfj67`, HTTP без TLS) — смените для боевого
> использования. См. раздел «Безопасность» в `DOCUMENTATION.md`.
