# HelpDesk — служба поддержки (аналог Яндекс Трекера)

Веб-система заявок/тикетов, работающая в Docker. Поддерживает три языка
(**русский** — основной, **английский**, **中文**), администрирование с
подтверждением регистраций, права доступа к подразделениям, задачи со
статусами / приоритетами / исполнителями / комментариями / вложениями /
сроками, архив закрытых заявок и настраиваемую цветовую палитру.

> A helpdesk / ticketing system (Yandex-Tracker-style), running in Docker,
> with RU/EN/ZH localization, admin approval flow, per-department access
> control, full ticket workflow, archive and an admin-editable color palette.

## Возможности

- **Страница входа** с кнопкой регистрации и переключателем языка.
- **Три языка** (RU/EN/ZH). Выбранный язык **запоминается для пользователя**
  (в профиле на сервере + `localStorage`).
- **Нейтральная палитра**, которую администратор меняет прямо из интерфейса
  (раздел «Настройки оформления»); изменения применяются мгновенно ко всем.
- **Каталог подразделений** (например, «Поломойки»). Админ создаёт/переименовывает/удаляет их.
- **Задачи как в Яндекс Трекере**: ключ (`ПОЛО-1`), статусы
  (открыта → в работе → нужна информация → решена → закрыта), приоритеты,
  типы, исполнитель, срок, описание, **комментарии (переписка)**,
  **вложения**, **история изменений**.
- **Клиентская часть**: пользователь регистрируется (почта + пароль + описание).
  Администратор получает **уведомление**, **принимает или отклоняет** заявку и
  **выдаёт доступ** к конкретным подразделениям (выпадающий список + галочки).
- **«Взять в работу»** — назначить заявку на себя и перевести в статус «В работе».
- **Архив**: закрытые заявки автоматически уходят в архив и хранятся там.

## Быстрый старт (Docker)

```bash
cd helpdesk
cp .env.example .env        # при желании поменяйте пароль администратора и SECRET_KEY
docker compose up --build
```

Откройте <http://localhost:8000>.

**Учётная запись администратора по умолчанию** (создаётся при первом запуске):

- Email: `admin@helpdesk.local`
- Пароль: `admin12345`

Смените их через переменные `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env`
**до первого запуска** (админ создаётся один раз, если база пуста).

## Как пользоваться

1. Войдите под администратором.
2. **Каталог → Новое подразделение** — создайте направление (напр. «Поломойки»).
3. Откройте подразделение → **Новая задача** — заведите заявку.
4. Пусть пользователь **зарегистрируется** на странице входа.
5. Админ: **Заявки на регистрацию** → **Принять**, выберите роль и отметьте
   галочками, какие подразделения пользователь может видеть.
6. Пользователь входит, видит доступные подразделения, открывает заявку,
   нажимает **«Взять в работу»**, ведёт переписку, меняет статус, прикрепляет
   файлы, ставит срок.
7. Перевод в статус **«Закрыта»** (или кнопка **«В архив»**) отправляет заявку
   в **Архив**.
8. **Настройки оформления** — измените палитру и название системы.

## Технологии

- **Backend**: FastAPI + SQLAlchemy (Python 3.12).
- **База данных**: SQLite по умолчанию (файл на volume). Легко переключается на
  PostgreSQL — задайте `DATABASE_URL` и раскомментируйте сервис `db` в
  `docker-compose.yml`.
- **Frontend**: одностраничное приложение на ванильном JavaScript (без сборки),
  палитра через CSS-переменные, i18n из JSON-словарей.
- Всё в одном контейнере; данные и вложения — в volume `helpdesk_data` (`/data`).

## Структура

```
helpdesk/
├─ backend/
│  └─ app/
│     ├─ main.py            # точка входа, монтирует статику фронтенда
│     ├─ models.py          # модели БД
│     ├─ schemas.py         # Pydantic-схемы
│     ├─ security.py        # хэш паролей, JWT
│     ├─ deps.py            # зависимости авторизации
│     ├─ seed.py            # создание админа при первом старте
│     └─ routers/           # auth, departments, tasks, comments, admin, notifications, settings
├─ frontend/
│  ├─ index.html
│  ├─ css/style.css
│  ├─ js/{i18n,api,app}.js
│  └─ i18n/{ru,en,zh}.json
├─ Dockerfile
├─ docker-compose.yml
└─ .env.example
```

## Разработка без Docker

```bash
cd helpdesk/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export DATABASE_URL="sqlite:///./helpdesk.db"
export UPLOAD_DIR="./uploads"
export FRONTEND_DIR="../frontend"
uvicorn app.main:app --reload --port 8000
```
